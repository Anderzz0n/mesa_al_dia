Cómo leerlos

Círculo oscuro con número → explicado en las notas bajo la pantalla («Por qué está así»).
Borde punteado con etiqueta → aparece solo en ese caso (por ejemplo «si hay un error»).
Gris punteado → deshabilitado, agotado o apagado.
Tarjeta con borde grueso → comanda anticipada (prioritaria). Encabezado oscuro → comanda con demora. Tarjeta punteada → comanda cancelada por acusar.
Interruptor → relleno oscuro y perilla a la derecha = sí; vacío = no.
SUPUESTO / POR CONFIRMAR → algo que no está en el diseño de la API o que depende del SRS.
