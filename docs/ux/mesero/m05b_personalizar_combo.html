Por qué está así

  1. Incluye: cada componente del combo con su casilla. Solo se pueden quitar los marcados como removible; el resto sale bloqueado con el motivo. El combo es un ítem «padre» y sus componentes son ítems «hijos» (los incluidos cuestan 0).
  2. Extras: productos adicionales con su cantidad; se suman al precio.

API (cuerpo de POST /cuentas/{id}/pedidos): un combo solo admite componentes_quitados y extras; no se personalizan las opciones de cada componente. Esta hoja no trae selector de modalidad (Mesa / Llevar / Anticipada): el ejemplo de cuerpo de la API no la incluye para combos. POR CONFIRMAR con el SRS: si un combo puede pedirse «Llevar».
