Ya no se pueden agregar pedidos: «Agregar productos» y «Marcar pendiente de pago» quedan desactivados.

Por qué está así

  1. Pedido reciente (< 3 min): el botón dice «Cancelar» con una cuenta regresiva; se cancela al instante. El servidor es quien manda: la app solo cambia el texto.
  2. Pasados los 3 min: el mismo botón pasa a «Solicitar cancelación» (caja decide). Debajo, el estado de cada comanda por destino y, si cocina confirmó menos ítems de los enviados, una alerta (RF7: coincide = falso).
  3. Solicitud en curso o rechazada (evento cancelacion.rechazada): el botón se reemplaza por el estado; si se rechazó, se puede volver a solicitar.
  4. Cancelado: tachado, sin acciones y fuera del total.
  5. Acciones fijas abajo: agregar productos (reusa M4 con esta cuenta), o marcar «pendiente de pago» cuando el cliente ya consumió. Una cuenta pendiente de pago (en proceso de pago) o pagada ya no acepta pedidos nuevos (decisión del equipo): ambos botones se desactivan. Las cancelaciones solo se bloquean con la cuenta pagada.

API: GET /cuentas/{id} · PATCH /cuentas/{id} · eventos comanda.recibida, comanda.estado, pedido.cancelado. Los 4 pedidos son variantes de ejemplo: en la app real se ven los que existan.
